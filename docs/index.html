fibtransponder

Fibonacci-Radix Streaming State Machine for Tokenization & Semantic Research

📋 Overview

fibtransponder v0.1.1 is a public-surface consistency release built around a Fibonacci-radix streaming state machine (FSVM).

This repository serves as a testable substrate for lower-level stream sensing relevant to tokenization and semantic harness research.

🎯 Canonical Thesis

  • The FSVM is the contribution.
  • Seed-only calibration is falsified.
  • Structural calibration via adjacency width is demonstrated.
  • Width selects locality sensitivity.
  • Threshold is a planned second axis, not yet a proven result.

✅ What This Repo Proves

  • A deterministic FSVM can ingest a bitstream with bounded per-step work while tracking dilation, zero-run markers, and a cheap state sketch.
  • Seed-only calibration does not create detector diversity. Different Zobrist seed tables change sketch identity, but not event structure.
  • Structural calibration is real when geometry changes. Varying adjacency width changes class sensitivity ranking.
  • Adjacency width already acts as a locality-sensitivity selector.

❌ What Is Not Claimed

  • This release does not claim threshold-based structural calibration.
  • This release does not claim tokenizer replacement, transformer replacement, or agent superiority.
  • This release does not claim that the current sketch is a sufficient semantic identity mechanism on its own.
  • This release does not claim broad convergence or proprioceptive control results beyond what is directly documented.
